# Accessibility

Contrast below is measured from the hex values in `apps/web/src/styles/tokens.css` (WCAG relative luminance). Text pairs need 4.5:1. UI boundaries and the focus ring need 3:1. Ratios are the ones the components actually use.

The focus ring is `outline: 3px solid var(--teal-500)` with `outline-offset: 2px` on `:focus-visible`. The offset gap shows the surface behind the control, so the ring is compared with that surface.

`prefers-reduced-motion: reduce` collapses animation and transition duration. Dialogs, drawers, tooltips, and toasts fade only when motion is allowed.

## Pairs that are not used for text or control boundaries

| Pair | Ratio | Why it is unused |
| --- | --- | --- |
| `--sand-50` on `--teal-500` | 3.89:1 | Below 4.5:1. Hover does not fill a control with teal-500 behind text. Hover draws the same 3px teal-500 outline, offset 2px, on the existing fill. |
| `--gold-500` on `--sand-50` | 2.97:1 | Below 3:1. Gold is a decorative swatch only. The swatch edge is teal-500. |
| `--gold-500` on `--sand-100` | 2.79:1 | Below 3:1. Not a border or label. |
| `--ink-900` on `--danger-600` | 2.24:1 | Below 4.5:1. Error text is danger-600 on sand-50, or sand-50 on a danger fill. |
| `--ink-900` on `--green-600` | 2.94:1 | Below 4.5:1. Positive labels use sand-50 on green-600. |
| `--green-600` on `--sand-100` | 4.44:1 | Below 4.5:1 for text. Fine as a UI edge (3:1), not as card text. |

`--danger-600` is limited to the delete button, the system-error badge, and the system-error toast title and border.

Direction follows the document: `lang="ar"` sets `dir="rtl"`, and `lang="en"` sets `dir="ltr"`. Spacing in the components uses logical properties (`ms` / `me` / `ps` / `pe` / `start` / `end`).
